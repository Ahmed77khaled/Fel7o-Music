# مهارة Fel7o Downloader المشتركة

> هذه المهارة مكتوبة بمعيار `SKILL.md` المفتوح، فيمكن استدعاؤها من Manus و Antigravity وأي وكيل آخر يدعم المعيار.

## متى تستخدمها

استخدمها **قبل** أي مهمة على مستودع `Fel7o-Music-`:
- تعديل أو مراجعة كود في هذا المشروع.
- تشخيص خطأ أو سلوك غير متوقع.
- كتابة توثيق أو تحديث `CHANGELOG`.
- تقييم مدى خطورة تغيير مطلوب.

## ما تحتويه

| الملف | المحتوى |
|---|---|
| `AGENTS.md` (جذر المشروع) | خريطة المشروع، عقود IPC الكاملة، القواعد الإلزامية، أوامر التشغيل، تعريف "منتهٍ" |
| `.agents/rules/10-fel7o-conventions.md` | قواعد تفصيلية: النطاق، العقود، الأمان، المحرّكات، الواجهة، قائمة ما قبل الدفع |
| `docs/COLLABORATION.md` | الأدوار، دورة العمل، تنسيق commits، فضّ الخلافات |
| `docs/TASKS.md` | من يعمل على ماذا الآن |
| `docs/HANDOFF.md` | ما حدث في آخر جلسة وما المطلوب منك |

## الحقائق الأساسية التي لا يجوز نسيانها

1. **JavaScript خام.** لا TypeScript، لا framework، لا bundler. لا تُضِف حزمة npm دون موافقة.
2. **واجهة عربية.** كل نص جديد للمستخدم بالعربية.
3. **ثلاث نقاط لكل قناة IPC:** `main.js` + `preload.js` + `AGENTS.md`.
4. **`window.fel7o` عقد ثابت.** لا تحذف أو تعِد تسمية دوال قائمة.
5. **الأمان غير قابل للتفاوض:** لا تلمس `sandbox: true` / `contextIsolation`، وتحقق من كل رابط قبل تمريره إلى yt-dlp.
6. **`attachProcessHandlers()` هو المسار الوحيد** لتشغيل yt-dlp/ffmpeg.
7. **لا دفع إلى `main`.** فرع + PR دائماً، مع سطرَي `Task:` و`Agent:` في رسالة الـ commit.
8. **`CHANGELOG.md` و`docs/TASKS.md` و`docs/HANDOFF.md`** تُحدَّث قبل الدفع.
9. **`bin/yt-dlp.exe` و`bin/ffmpeg.zip`** مدمجان عمداً — لا تحذفهما.
10. **`src/renderer.js` و`src/styles.css` ملفان كبيران** — تعديلاتهما تحتاج عناية، ووكيل واحد فقط يعمل عليهما في الوقت نفسه.

## نقاط الهشاشة المعروفة

| النقطة | الخطر |
|---|---|
| تحليل مخرجات yt-dlp النصية | تتغيّر مع تحديثات yt-dlp وتُنتج أخطاء صامتة |
| `assets/icon.ico` مفقود | `package.json` يشير إليه — البناء قد يفشل أو يستخدم أيقونة افتراضية |
| لا توجد اختبارات ولا CI | لا شيء يمنع كسر الوظائف القائمة عند الدفع |
| لا آلية لتحديث yt-dlp | يوتيوب يتغيّر باستمرار وكسر التحميل متوقع بمرور الوقت |
| المستودع عام وثنائيات محرّكات ملتزمة فيه | تضخّم الحجم بشكل تراكمي |

```
٤. فرع جديد: <agent>/T-0xx-slug

٧. ادفع وافتح PR مع وسم collaboration
```
