## H-001 — تفعيل طبقة التعاون بين Manus و Antigravity

**التاريخ:** 2026-10-15
**المهمة:** T-001
**المنفّذ:** Manus
**الفرع:** `collab/manus-antigravity-setup`

### ما تم

إنشاء طبقة تعاون كاملة داخل المستودع تعمل بمعايير مشتركة بين الوكيلين:

- **`AGENTS.md`** في جذر المشروع — يقرأه Antigravity تلقائياً. يحتوي على: خريطة المشروع، جدول عقود IPC الكامل (26 قناة)، القواعد الإلزامية (الأمان، الكود، الواجهة)، الأوامر، تعريف "منتهٍ"، وبروتوكول التعاون.
- **`.agents/rules/10-fel7o-conventions.md`** — قواعد تفصيلية إضافية يقرأها Antigravity آلياً.
- **`.agents/skills/fel7o-shared/SKILL.md`** — مهارة مشتركة بمعيار `SKILL.md` المفتوح.
- **`docs/COLLABORATION.md`** — البروتوكول الكامل: جدول مقارنة القدرات، الأدوار المحددة، دورة العمل بـ 6 خطوات، تنسيق الـ commits، إعداد MCP الاختياري، وإجراء فضّ الخلافات.
- **`docs/TASKS.md`** — لوحة مهام حيّة بـ 8 مهام مبدئية موزّعة على الوكيلين.
- **`docs/HANDOFF.md`** — هذا الملف.

### القرارات المعمارية المتخذة

1. **Git هو الجسر الوحيد** — لا حاجة لأي إعداد إضافي لإطلاق التعاون.
2. **قواعد مشتركة عبر `AGENTS.md`** — ملف واحد يقرأه الطرفان، فلا يوجد مصدران للحقيقة يمكن أن يتباعدا.
3. **لا دفع مباشر إلى `main`** — كل تغيير عبر فرع + PR.
4. **وسم كل commit بهوية الوكيل** عبر سطر `Agent:` — يجعل النسبة والمسؤولية قابلة للتتبع دائماً.
5. **MCP مؤجّل** — ربط مباشر بين الوكيلين يتطلب بيئة دائمة (Persistent VM) بخادم MCP مستقر، وبيئة Manus السحابية مؤقتة. Git يكفي الآن.

### ما كشفه الفحص الأولي للمشروع

- المستودع **عام (public)** — يستحق مراجعة إن كان من المفترض أن يكون خاصاً.
- `bin/yt-dlp.exe` و`bin/ffmpeg.zip` مُلتزَمان في Git — سيؤدي هذا لتضخّم المستودع مع كل تحديث لـ yt-dlp. مقترح في **T-008**.
- `assets/icon.ico` مشار إليه في `package.json` لكنه **غير موجود** في المستودع — **T-004**.
- لا يوجد أي نظام اختبارات آلي ولا CI — **T-003**.
- البنية العامة سليمة: فصل واضح بين العملية الرئيسية والـ preload والـ renderer، وتحقق من الروابط، و`sandbox: true` مُفعّل، ومعالجة أخطاء موحّدة عبر `attachProcessHandlers()`.

### المطلوب من الطرف الآخر (المطوّر ← ثم Antigravity)

1. **دمج هذا الـ PR** في `main`.
2. في جهازك — بعد الدمج:
   ```bash
   git checkout main
   git pull
   ```
3. تأكد أن Antigravity يقرأ ملف `AGENTS.md` (يفعل ذلك تلقائياً من جذر المشروع).
4. **اختياري — تفعيل إدارة GitHub من داخل Antigravity:** راجع القسم 6 في `docs/COLLABORATION.md`.
5. ابدأ من **T-002** في `docs/TASKS.md`.

> **مسار مقترح:** أنت (المطوّر) تدمج → Antigravity ينفّذ **T-002** و**T-004** → Manus ينفّذ **T-003** و**T-005** بالتوازي → مراجعة متبادلة للـ PRs.

### مخاطر أو نقاط معلّقة

- لم يُجرَّب أي تشغيل فعلي للتطبيق بعد — كل الاستنتاجات أعلاه من قراءة الكود فقط. **T-002** هو ما يحوّل هذا إلى حقائق.
- افتراض غير مؤكَّد: أن Antigravity على جهاز المطوّر مُهيّأ بصلاحية دفع (push) إلى المستودع.
